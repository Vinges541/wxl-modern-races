# Security

These tools parse binary assets and patch a legacy executable. Use trusted
exports and the exact supported versions. Do not run as administrator/root or
disable path, hash or process checks. Keep package and client directories free
from concurrent writers during installation. The game client is not sandboxed
by these tools.

Report vulnerabilities privately to the repository owner, using GitHub private
vulnerability reporting when enabled. Include affected versions and reproduction
steps with synthetic samples; do not attach game files, credentials or memory
dumps. Avoid publishing exploit details before the issue can be addressed.
